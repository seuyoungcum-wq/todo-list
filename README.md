# 오늘의 할 일 (TodoList 웹애플리케이션)

하루의 할 일을 신속하고 직관적으로 추가, 완료, 관리할 수 있는 고품질 한국어 개인용 TodoList 웹애플리케이션입니다.

---

## 1. 주요 기능

| 기능 카테고리 | 상세 설명 |
| :--- | :--- |
| **날짜(YYMMDD) 지정** | • 할 일 생성 및 수정 시 `YYMMDD` 형태(예: `261126`)로 마감/목표 날짜를 직접 입력 가능<br>• 기본값은 오늘 날짜로 자동 설정되며, 잘못된 날짜 입력 시 방어적 보정<br>• 목록에서 날짜와 함께 '오늘', '내일' 뱃지가 자동으로 시각화됨 |
| **범주(카테고리) 선택** | • `업무`, `개인`, `건강`, `취미` 등 할 일의 범주를 간편하게 탭 버튼으로 선택<br>• 각 범주별 전용 테마 색상 뱃지(업무-파랑, 개인-보라, 건강-에메랄드, 취미-오렌지) 부여<br>• 툴바에서 범주별 필터링 기능 제공 |
| **오늘 & 내일 맞춤형 대시보드** | • **'오늘 남은 할 일 N개'**: 오늘(및 이전 지연) 목표 중 미완료된 항목 수를 상단에 강조 표시<br>• **'내일 해야 할 일 N개'**: 바로 아래에 내일 날짜로 예정된 할 일 수를 명확히 안내<br>• 전체 통계(전체/완료/달성률 %) 및 프로그레스 바 제공 (0 나눗셈 방어) |
| **할 일 추가 및 한글 IME 보호** | • `Enter` 키 또는 `추가` 버튼 등록, 앞뒤 공백 자동 제거 및 최대 200자 제한<br>• `isComposing` 상태를 감지하여 한글 조합 중 `Enter` 입력 시 중복 등록을 원천 차단<br>• 추가 완료 후 입력창 자동 초기화 및 포커스 유지, 최신순 정렬 |
| **완료 상태 관리** | • 접근 가능한 커스텀 체크박스(`role="checkbox"`, `aria-checked`) 토글<br>• 완료 시 취소선 및 색상 감쇄 적용 |
| **인라인 내용 수정** | • 수정 버튼 클릭 시 인라인 편집 모드로 전환하여 텍스트, 범주, 날짜 모두 수정 가능<br>• `Enter` 저장, `Esc` 취소, 빈 내용 저장 차단 |
| **삭제 및 실행 취소 (Undo)** | • 개별 항목 삭제 시 즉시 목록에서 제거하고 5초 동안 실행 취소 토스트 노출<br>• "실행 취소" 클릭 시 원래 인덱스 위치로 정확히 복원 |
| **상태 필터 및 검색** | • `전체` / `진행 중` / `완료` 탭 필터링 (`role="tab"`, `aria-selected`)<br>• 할 일 내용, 범주, 날짜(YYMMDD) 실시간 통합 검색 및 원클릭 지우기 버튼 |
| **완료 항목 일괄 정리** | • 완료된 항목이 없으면 비활성화(`disabled`), 확인 모달 대화상자(포커스 트랩, `Esc` 지원) 제공 |
| **자동 저장 및 안정성** | • `localStorage`에 자동 저장 및 브라우저 새로고침 시 자동 복원<br>• 스키마 버전 관리 및 레거시 데이터/손상 JSON 자동 보정 |

## 2. 실행 및 빌드 방법

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행 (기본 포트: 5173 또는 5174)
npm run dev

# 단위 및 통합 테스트 실행 (Vitest)
npm run test

# 프로덕션 빌드 및 타입 검사
npm run build
```

## 3. 데이터 저장 방식 및 제한사항

> [!IMPORTANT]
> **저장 범위 및 제한사항 안내**
> - 본 애플리케이션의 모든 데이터는 **현재 브라우저의 `localStorage`**에만 저장됩니다.
> - 별도의 서버 백엔드, 회원 로그인, 유료 클라우드 동기화 서비스가 없으므로 다른 기기나 다른 브라우저 간에는 데이터가 동기화되지 않습니다.
> - 브라우저 캐시 및 사이트 데이터를 초기화하면 저장된 할 일 데이터가 영구적으로 삭제될 수 있습니다.
