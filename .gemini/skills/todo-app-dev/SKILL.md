# TodoList 웹앱 개발 및 검증 스킬

## 개요
본 스킬은 React + TypeScript 기반의 고품질 TodoList 웹앱을 개발하고 유지보수할 때 준수해야 할 디자인 토큰, 접근성(A11y), 상태 관리 및 테스트 규칙을 정의합니다.

## 핵심 가이드라인
1. **한글 IME 처리**:
   - `e.nativeEvent.isComposing`이 참일 때는 Enter 키 이벤트 핸들러를 조기 반환(`return`)하여 글자가 중복 입력되거나 조합 도중 등록되는 문제를 차단합니다.
2. **접근성(WCAG 2.1 AA)**:
   - 모든 버튼과 체크박스는 명확한 레이블(텍스트 또는 `aria-label`)을 제공합니다.
   - 모달 대화상자는 포커스 진입, Trapping, Esc 탈출, 원래 위치로의 포커스 복귀를 반드시 보장합니다.
   - 대비율은 최소 4.5:1 이상을 유지합니다.
3. **데이터 안정성**:
   - `localStorage` 파싱 오류 시 데이터를 날리지 않고 방어적 fallback을 적용합니다.
   - 저장 실패 시 앱이 중단되지 않고 사용자에게 경고 배지를 표시합니다.
